Quick Reference

Python Developer Cheat Sheet

Essential built-in functions, methods, and syntax patterns at your fingertips.

Core Built-in Functions

Built-ins
  • print(*values, sep=' ') Outputs to console
  • len(sequence) Returns item count
  • type(object) Returns data type
  • range(start, stop, step) Generates number sequence
  • enumerate(iterable) Pairs index and item
  • zip(*iterables) Combines multiple iterables
  • sorted(iterable, reverse=False) Returns sorted list

Common String Methods

Strings
  • s.strip() Removes surrounding whitespace
  • s.split(delimiter) Splits string into list
  • delimiter.join(list) Joins list into string
  • s.replace(old, new) Replaces substrings
  • s.startswith(prefix) Checks prefix condition
  • s.lower() / s.upper() Case conversion
  • f"{variable}" Modern string interpolation

Data Structures Syntax

Collections
  • lst.append(x) Add element to list end
  • lst.pop(index) Remove & return item
  • [x**2 for x in nums] List comprehension
  • d.get(key, default) Safe dictionary retrieval
  • d.items() Returns (key, value) pairs
  • set_a | set_b Set union operation
  • set_a & set_b Set intersection

OOP & Exception Handling

Patterns
  • class Child(Parent): Inheritance definition
  • def __init__(self): Object constructor
  • try: ... except Err as e: Error catching block
  • finally: Always executed cleanup block
  • with open(file) as f: Safe context manager
  • raise ValueError("msg") Explicitly trigger error
  • lambda x: x * 2 Anonymous inline function
